## What's new in v0.4.0

### Features

- **Arrangement Timeline is now a complete editor.** Lay out and edit clips on a real timeline synced to your project's tempo: split clips with the blade tool, group and collapse tracks, multi-select and drag groups of clips at once, snap to a grid, add markers, and loop or seek by beat.
- **Live waveforms and video thumbnails** on the timeline, updating as you scrub instead of showing a stale cached preview.
- **A render/export queue** — pick an exact range to render, queue up multiple exports, and keep working while they run in the background without interrupting playback.
- **Drag and drop media straight onto the timeline** to add it.
- **Better time-stretching for samples**, fixing pitch artifacts and drift between what you see in the waveform and what actually plays back.
- **Smarter sample BPM handling** — BPM is auto-detected and remembered per clip, and clip length stays consistent whether or not "Sync to Tempo" is on.
- Clip opacity, fades, pitch-sync, and pan; the mix strip (Solo/Mute/Pan/Gain/Opacity) is back on the track header.
- **Infinite is now available on Linux** as a real, downloadable app for the first time — see "Linux" below.
- Shift-drag Q on the EQ curve for finer control.
- "Install AI Skill" buttons in Settings for Field Language and Expression Globals, to hand to any AI coding assistant.
- A new Keyboard node for notes.
- UV wrap mode (clamp/repeat/mirror) on Material.

### Fixes

- Fixed clips retriggering unexpectedly, and text fields losing focus unexpectedly while typing in the arrangement view.
- Fixed drag-and-drop from Finder landing in the wrong place instead of the timeline.
- Fixed stuttering while scrubbing the timeline, sample/track playback glitches, and color issues in exported video.
- Fixed a crash generating certain meshes with Metaballs on Intel Macs.
- Fixed a crash opening the search panel.
- Fixed Windows display scaling issues and added a manual UI Scale override for when it still looks off.
- Fixed the VST3 plugin scanner incorrectly hiding valid plugins on macOS.
- Fixed a crash when removing a VST3 plugin search folder.
- Fixed modulated integer sliders sometimes overwriting your recorded automation.
- Fixed issues with Note Stack's semitone offsets and the Wavetable Shaper's table dropdown.
- Cleaned up the right-click menu on performance-matrix controls to remove options that didn't apply there.

### Linux

**Infinite ships on Linux for the first time**, as a single downloadable file (`Infinite-x86_64.AppImage`) — no installer, no extra packages to install first.

It's been tested on Ubuntu 22.04, Ubuntu 24.04, Debian 12, Fedora, and Arch Linux, covering plugin hosting (VST3, with plugin windows), audio and MIDI, video and camera, and background removal.

**Please note:** this is an early-access build. It's been thoroughly tested in automated environments, but hasn't yet been through a round of real-world use on real hardware — different GPUs, audio interfaces, MIDI controllers, and desktop setups. A native Wayland desktop session hasn't been verified yet either (X11 is). If you run into issues, please report them on [GitHub issue #14](https://github.com/n1m21n/Infinite/issues/14) — that feedback is exactly what this release needs.
